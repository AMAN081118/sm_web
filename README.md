# Smart Manufacturing Department Website

## Overview

The Smart Manufacturing Department Website is an official platform developed to present the department’s vision, academic programs, research initiatives, and technological infrastructure. It serves as a centralized interface for students, faculty, and industry stakeholders to access relevant information, updates, and resources related to smart manufacturing department.
